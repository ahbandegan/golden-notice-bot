# 🪙 ربات تلگرامی اعلام نرخ لحظه‌ای طلا، سکه و ارز
### (Golden Notice Telegram Bot)

این ربات با فریم‌ورک قدرتمند **Telegraf** و به زبان **TypeScript / Node.js** توسعه داده شده است. این سیستم نرخ‌های زنده و رسمی طلا، انواع مسکوکات و دلار را از وب‌سرویس GFw دریافت کرده و طبق زمان‌بندی دلخواه شما به کانال یا گروه ارسال می‌کند. همچنین دارای سیستم **مدیریت چند ادمین**، **گزارش خودکار خطاها**، **عضویت اجباری** و **ماشین‌حساب هوشمند طلا و سکه** در داخل ربات است.

---

## ✨ امکانات و قابلیت‌ها

### 👑 ۱. پنل مدیریت حرفه‌ای (در پیوی ربات)
* **پشتیبانی از چندین ادمین (Multi-Admin):** امکان افزودن و حذف نامحدود ادمین‌ها با Chat ID از داخل پنل بدون نیاز به تغییر دستی فایل‌ها.
* **ارسال خودکار زمان‌بندی‌شده:**
  - حالت دوره‌ای (هر ۱۵ دقیقه، ۳۰ دقیقه، ۱ ساعت، ۲ ساعت، ۴ ساعت، ۶ ساعت)
  - حالت ساعات مشخص در روز (مانند ۱۱:۰۰، ۱۴:۳۰، ۱۸:۰۰ یا تعریف ساعت‌های دلخواه)
* **تنظیم سریع مقصد ارسال:** امکان معرفی کانال یا گروه با فوروارد پیام، ارسال آیدی عددی (`-100...`) یا یوزرنیم کانال.
* **تشخیص خودکار افزودن به کانال:** به محض اد شدن ربات در یک کانال یا سوپرگروه، ربات در پیوی ادمین پیام داده و دکمه تنظیم سریع را نمایش می‌دهد.
* **فیلتر و مدیریت نمادها:** فعال یا غیرفعال کردن هر یک از اقلام طلا، سکه یا ارز با یک کلیک.
* **تنظیم امضای اختصاصی:** شخصی‌سازی متن یا یوزرنیم انتهای پیام‌ها.

### 🚨 ۲. سیستم هوشمند مانیتورینگ و گزارش خطا (Error Reporting)
* در صورت بروز هرگونه قطعی در وب‌سرویس، خطای ارسال تلگرام یا محدودیت Rate Limit، ربات فوراً گزارش کامل خطا به همراه زمان دقیق شمسی و منبع خطا را ارسال می‌کند.
* مقصد دریافت خطاها در پنل قابل تنظیم است (ارسال به پیوی تمام ادمین‌ها یا یک کانال/سوپرگروه اختصاصی لاگ).
* دارای سیستم محافظتی ضد اسپم (Cooldown) جهت جلوگیری از ارسال پیام‌های تکراری هنگام قطعی طولانی شبکه.

### 🔒 ۳. سیستم عضویت اجباری (Forced Membership)
* امکان فعال‌سازی قفل عضویت اجباری در کانال دلخواه ادمین.
* در صورت فعال بودن، کاربران عادی قبل از استعلام قیمت یا استفاده از ماشین‌حساب باید ابتدا در کانال عضو شده و دکمه تایید را لمس کنند.

### 👤 ۴. بخش کاربران عادی در خود ربات
* استعلام قیمت‌ها در چت خصوصی به صورت پیام شیک با اعداد فارسی، تقویم جلالی و نشانگرهای درصد تغییرات.
* ماشین‌حساب تعاملی در پیوی (محاسبه قیمت طلا و سکه بر اساس وزن یا تعداد وارد شده توسط کاربر).
* بخش راهنما و معرفی کانال.

### 💾 ۵. ذخیره‌سازی داده‌ها (بدون نیاز به دیتابیس)
* ذخیره‌سازی بدون نیاز به دیتابیس (کاملاً مبتنی بر فایل `data/settings.json`) با قابلیت بکاپ‌گیری و انتقال بسیار آسان.

## 🛠 اسکریپت نصب و مدیریت جامع (`install.sh`)

یک اسکریپت شکیل، رنگی و تعاملی به زبان **انگلیسی** برای سرورهای لینوکس آماده شده است که تمام فرآیندهای نصب داکر، نصب سرویس لینوکس، آپدیت و حذف را انجام می‌دهد:

```bash
chmod +x install.sh
sudo ./install.sh
```

**منوی این اسکریپت شامل گزینه‌های زیر است:**
1. **`Install & Start with Docker`** (راه‌اندازی کامل کانتینر ایزوله با داکر و داکر کامپوز)
2. **`Install & Start with Node.js & Systemd`** (کامپایل سورس و ساخت سرویس سیستمی `golden-bot.service`)
3. **`Update Bot`** (دریافت آخرین تغییرات گیت، کامپایل مجدد و ری‌استارت سرویس)
4. **`View Live Logs`** (مشاهده لحظه‌ای لاگ‌های سیستم)
5. **`Restart Bot Service`** (ری‌استارت سرویس)
6. **`Stop Bot Service`** (توقف ربات)
7. **`Uninstall & Clean Up`** (حذف کامل سرویس و پاکسازی)

## 🚀 راهنمای اجرای دستی پروژه

### ۱. اجرای مستقیم با Node.js:
```bash
# نصب وابستگی‌ها
npm install

# ساخت و اجرای پروداکشن:
npm run build
npm start
```

### ۲. اجرا با Docker Compose:
```bash
docker compose up -d --build
```
